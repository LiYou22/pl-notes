\chapter{Week 5: From Substitution to Environments}
\label{ch:week5}

Lecture 5: October 6, 2026. Recitation 5: October 9, 2026.

Supplementary reading:

  \item \cite{PLAI} Chapter 6 (From Substitution to Environments) and Chapter 7 (Functions Anywhere), which make exactly this chapter's move and hit the same dynamic-scope bug on the way.
  \item \cite{SICP} Section 3.2 (The Environment Model of Evaluation), for the same idea drawn as frames and pointers.
  \item \cite{Scott} Chapter 3 (Names, Scopes, and Bindings), for static and dynamic scope with assignment and for macros (\Cref{sec:rec5}).
  \item \cite{TAPL} Sections 5.1--5.3 (the untyped lambda calculus), optional.
\end{itemize}

\Cref{ch:week4} implemented names and functions by \emph{substitution}: rewrite the program, replacing a name by its value, before running it. This chapter first finishes that story, then keeps the language and changes the implementation. An \emph{environment} interpreter never rewrites the program; it carries a table from names to values and looks a name up when it reaches it. We build it in five small versions, called 5a to 5e below, and twice the first attempt gets scope wrong in the same way. The last section revisits environments and scope, and carries the scope question over to assignment and macros. This chapter covers:
\begin{itemize}
  \item \Cref{sec:substrev}: \code{let} as function application, capture once more, the lambda calculus, and $\alpha$-equivalence;
  \item \Cref{sec:env}: an environment interpreter for \code{let}, checked against substitution (version 5a);
  \item \Cref{sec:dynscope}: lazy \code{let} with environments, dynamic scope, and the fix (versions 5b and 5c);
  \item \Cref{sec:closures}: functions with environments, and closures (versions 5d and 5e);
  \item \Cref{sec:rec5}: Recitation~5, environments as functions, one interpreter for both scopes, scope with assignment, and hygienic macros.
\end{itemize}
