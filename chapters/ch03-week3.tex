From this chapter on, code is written in \code{\#lang plai-typed}, the language of \cite{PLAI}: Racket with a type checker that reads the whole program before anything runs. We introduce its types, define new types with \code{define-type}, and use them to write a first interpreter for a language of our own, a calculator. The last section redoes the Boolean-expression interpreter of \Cref{sec:rec2} with types and then studies Racket's \code{match} in more depth. This chapter covers:
\begin{itemize}
  \item \Cref{sec:types}: types, type inference and annotations, function types, homogeneous lists, pairs, and polymorphism;
  \item \Cref{sec:definetype}: \code{define-type}, \code{type-case}, and exhaustiveness checking;
  \item \Cref{sec:calc}: quote and s-expressions, concrete vs.\ abstract syntax, and the calculator's parser and interpreter;
  \item \Cref{sec:rec3}: Recitation~3, typed Boolean expressions and pattern matching with \code{match}.
\end{itemize}
